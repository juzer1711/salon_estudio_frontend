# Salón de Estudio – Frontend

Aplicación SPA desarrollada con React + Vite + TypeScript, siguiendo buenas prácticas de arquitectura, accesibilidad (WCAG) y calidad de código.

---

## 🚀 Tecnologías

- React
- Vite
- TypeScript
- React Router
- TailwindCSS
- ESLint + Prettier
- eslint-plugin-jsx-a11y (accesibilidad)
